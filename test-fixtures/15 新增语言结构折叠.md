# 新增语言结构折叠

这些片段刻意减少缩进，检查折叠是否来自语法结构。

```yaml
items: [
1,
2
]
description: |
  first
  a  b
next: true
```

```scss
.scss-panel {
.child {
color: red;
}
}
```

```less
.less-panel {
.child {
color: blue;
}
}
```

```xml
<root>
<child>
value
</child>
</root>
```

````markdown
# First section
paragraph
## Nested section
body
# Next section
last
````

```sql
SELECT
name,
id
FROM employees;
SELECT 1;
```

```php
function plainRun() {
return [
1,
2
];
}
```

```php
<?php
function taggedRun() {
return 1;
}
?>
```
