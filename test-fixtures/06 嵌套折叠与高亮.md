# 06 嵌套折叠与高亮

跨行注释和内部字符串在拆行后应保留高亮；折叠和展开不改变 code.textContent，复制仍应包含隐藏代码。

```java
class Highlighted {
    /* first line {
       second line } */
    String text() {
        return "a  b";
    }
}
```

有序列表围栏与列表标记同行。

1. ```js
   function ordered(x) {
       if (x) {
           return x + 1;
       }
       return 0;
   }
   ```

无序列表对照。

- ```js
  function unordered(x) {
      if (x) {
          return x + 1;
      }
      return 0;
  }
  ```

> [!note]+ 引用容器内的折叠
>
> ```python
> def quoted(values):
>     for value in values:
>         if value:
>             print(value)
> ```

CSS 嵌套规则。

```css
@media (max-width: 700px) {
    .box {
        display: grid;
        gap: 12px;
    }
}
```

TypeScript 与 TSX。

```typescript
function generic<T>(value: T): { value: T } {
    if (value) {
        return { value };
    }
    return { value };
}
```

```tsx
function Button({ label }: { label: string }) {
    return (
        <button type="button">
            <span>{label}</span>
        </button>
    );
}
```
