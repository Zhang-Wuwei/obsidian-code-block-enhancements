# 输入与范围回归

普通中文正文用于逐字输入、连续替换和删除回归，原文不得被显示功能改写。

```js
function run(){
  return 1;
}
```

引用内列表的缩进变化需要重新识别围栏结构。

> - ```python
>   def run():
>     return 1
>   ```

外层 Markdown 示例只产生一个代码块，内层围栏文字不能成为独立按钮。

````markdown
```js
const sample = 1;
```
````

尾部正文保持不变。
