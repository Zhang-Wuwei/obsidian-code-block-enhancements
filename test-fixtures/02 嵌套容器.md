# 02 嵌套容器

光标先放在这个段落，检查渲染后的 Callout 按钮。

> [!note]+ 展开 JS
>
> ```js
> function uniqueQuery(x){return {value:x,items:[1,2,3]};}
> ```

先手动展开默认折叠容器；格式化后应保持展开，显示成功提示。

> [!tip]- 默认折叠 CSS
>
> ```css
> .unique-css{display:flex;gap:12px;align-items:center}
> ```

- 列表外层保护标记。

  > [!note]+ 列表容器
  >
  > ```json
  > {"source":"list","values":[1,2,3]}
  > ```

紧凑引用前缀。

> [!note]+ 紧凑前缀
>
>```js
> function compact(x){if(x){return x+1;}return 0;}
>```

重复内容在没有可靠位置的实时预览中应拒绝猜测，且只标记当前按钮；阅读视图和光标进入代码后的编辑器按钮应能按位置处理。

> [!note]+ 重复 A
>
> ```js
> const duplicate={label:"same",values:[1,2,3]};
> ```

两个块之间的保护标记。

> [!note]+ 重复 B
>
> ```js
> const duplicate={label:"same",values:[1,2,3]};
> ```

退出按钮、点击另一个按钮、滚轮滚动、切换视图后，不应残留旧提示或标记到其他块。
