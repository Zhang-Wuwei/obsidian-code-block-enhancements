# 05 围栏边界

波浪号围栏。

~~~json
{"fence":"tilde","values":[1,2,3]}
~~~

四反引号包含三个反引号字符串。

````javascript
const fence="```";const sample={opening:`${fence}js`,body:"const x={a:1};",closing:fence};
````

Tab 与空格混合缩进；不支持格式化的语言应保持这些源码字符。

```java
class Tabbed {
	void run() {
		System.out.println("tab");
	}
}
```

引用外面的保护标记。

> 普通引用内的围栏。
>
> ```css
> .quoted{padding:8px;color:red}
> ```

不同内容、相同语言的两个短块。

```js
const first={name:"first",value:1};
```

中间的保护段落。

```js
const second={name:"second",value:2};
```
