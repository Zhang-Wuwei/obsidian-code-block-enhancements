# 04 结构折叠

注释和字符串里的括号不应成为错误的结构范围。折叠和换行不得改变源码。

```java
class EmployeeServer {
    record Employee(int id, String name) {
        String json() {
            return "{ fake brace }";
        }
    }
    static void main(String[] args) {
        // } must not end a structure
        for (int i = 0; i < 3; i++) {
            System.out.println("长字符串：https://example.invalid/a/very/long/path?department=engineering&active=true&pageSize=100" + i);
        }
    }
}
```

```python
class Box:
    def show(self, values):
        for value in values:
            if value:
                print("{ not a block }", value)
```

```c
int main(void) {
    const char *s = "} not code";
    for (int i = 0; i < 3; i++) {
        if (i) {
            puts(s);
        }
    }
}
```

```cpp
struct Box {
    int value;
    int get() const {
        return value;
    }
};
```

```go
package main
func main() {
    for _, value := range []int{1,2,3} {
        println(value)
    }
}
```

```rust
fn main() {
    for value in vec![1, 2, 3] {
        println!("{}", value);
    }
}
```

```javascript
async function queryEmployees(query) {

    }
    return [];
}
```
