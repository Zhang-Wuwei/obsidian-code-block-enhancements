# 09 重复代码定位

## 1. 两个相同容器

光标停留在此段，再分别格式化 A、B；每次只允许改变被点击的代码块。

> [!note]+ 相同标题
>
> ```js
> const duplicate={label:"same",values:[1,2,3]};
> ```

两个容器之间的保护正文。

> [!note]+ 相同标题
>
> ```js
> const duplicate={label:"same",values:[1,2,3]};
> ```
