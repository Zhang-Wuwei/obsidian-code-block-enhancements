# 07 箭头与留白

JSX 标签和表达式都应能折叠；同一行只显示一个入口。

```jsx
const EmployeeList = ({ items, onSelect }) => (
  <section className="employees">
    <h2>员工列表</h2>
    <ul>
      {items.map((item) => (
        <li key={item.id}>
          <button type="button" disabled={!item.active} onClick={() => onSelect(item)}>
            {item.name}
            <span>{item.department ?? "未分配"}</span>
          </button>
        </li>
      ))}
    </ul>
  </section>
);
```

不支持结构折叠的语言也应保持相同的正文左边距，不得退化为 4px。

```vue
<template>
  <section class="panel">
    <h2>{{ title }}</h2>
  </section>
</template>
<script setup lang="ts">
const title = "员工列表";
</script>
```

SCSS 对照。

```scss
$gap: 12px;
.panel {
  display: grid;
  gap: $gap;
  &:hover {
    color: blue;
  }
}
```

Less 对照。

```less
@gap: 12px;
.panel {
  display: grid;
  gap: @gap;
}
```

YAML 对照。

```yaml
name: test
items:
  - id: 1
    name: first
  - id: 2
    name: second
```
