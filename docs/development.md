# 开发与验证

唯一开发源是克隆后的源码目录。Vault 插件目录只安装发行文件，不在其中改源码。

## 本地版本管理与验收责任

Codex 负责在已确认需求范围内维护本地提交历史；按完整功能或修复单元，在验证通过并检查暂存差异后提交，使用中文提交信息。不将中间失败状态、个人配置、真实笔记、模型原始日志或生成包混入源码提交。远程推送、公开发布与正式 Vault 部署按各自适用授权执行，不由本地提交权限推导。

首次基线从当前 0.4.2 建立。此前没有 Git 提交，旧发行包和备份仅作为本地历史材料，不倒造过去各版本的提交。以后用实际提交记录修改与验证状态；区分已提交源码、测试库安装与正式库安装的版本。

实现者承担测试责任：按变更验证目标行为、边界保护与受影响的既有功能，界面或宿主行为须在测试库实际检查。用户的试用与场景反馈是补充验收，不能代替开发者测试。报告只陈述已验证范围，记录未覆盖项目。

格式化按钮借用原生 copy-code-button 外观类，编辑器另复用 code-block-flair；不绑定复制处理。自有样式只控制尺寸、定位、可见性和键盘焦点，不覆盖主题的悬停颜色。查找原生语言标记时必须排除 .qn-format-button，避免把自身当成定位参照；原生复制按钮的非悬停隐藏规则也不能破坏格式化按钮的键盘可达性。共享围栏缓存须通过导出的清理入口在卸载时释放，启停回归不得只检查命令退出码。

## 本地流程

```sh
npm ci --ignore-scripts
npm run check
npm run test:vault:reset
npm run test:vault:install
```

测试 Vault 固定为仓库内 `test-vault/`。reset 会重建合成测试笔记及该测试环境的配置，不应用于真实知识库。install 只写测试 Vault 的插件文件，保留现有 data.json。其目录和子目录不得使用指向外部的符号链接或 Junction。

需要界面验收时，在 Obsidian 中打开测试 Vault。CLI 显式指定 `vault=test-vault`，并核对实际路径。Windows 包装脚本可通过环境变量指定 CLI：

```powershell
$env:OBSIDIAN_CLI = '安装目录\Obsidian.com'
.\obsidian-test.ps1 eval 'code=app.vault.adapter.basePath'
```

分别验证源码视图、实时预览和阅读模式；包括普通代码、列表、Callout、默认折叠容器、重复代码、错误语法、未知语言、撤销及保存。测试后确认围栏外正文和其他代码块不变，格式化按钮不随光标移动，折叠后正文没有旧高度空白。

设置页分组不应使用 aria-label 作为整组悬停说明；使用 role=group 和 aria-labelledby 引用可见标题。真实宿主回归应比较同一节点：现有属性下不生成分组气泡，临时加回 aria-label 后生成气泡，再在 finally 中还原。Obsidian 1.14.5 的实际委托事件为 pointerover/pointerout，默认延迟约 1000ms；不能用未命中监听器的 mouseover 测试替代，也不能把脚本派发事件称为物理鼠标实测。

插件初始化与设置保存不得主动全量清空阅读页。后台窗口的原生动画帧调度可能暂停，插件启停时宿主自身也会重绘；发现空白时先记录窗口可见性、源码长度、区段与队列状态，并做无插件对照。不要在插件中永久关闭后台节流或轮询重置宿主私有渲染队列。

## 依赖与修改

设置页先展示三种工具的对应表，Java 并入 Prettier 并注明“含 Java 扩展”，再展示 Prettier 偏好。工具概览与下载说明置于同一说明卡片，设置区域统一左侧对齐，详情内容使用轻量边界与主题代码背景。显示范围和下载条件直接可见，语言白名单、详细边界和代码对照使用原生 details/summary，默认折叠，保留展开标记和键盘焦点；不引入额外设置持久化。测试须保留 18 个控件和原选项值，展开详情、切换视图或重新打开设置页都不能改写用户设置。样式只限定在 .qn-settings 内，深色外观测试临时切换测试窗口的主题类后必须恢复，不能修改用户主题配置。

Prettier 固定 3.7.4，Markdown AST 依赖固定 2.0.2；其他安装版本由锁文件确定。升级需要重新测试各语言与嵌入语法，并核对第三方许可清单。浏览器 standalone 不自动读取用户配置脚本或下载解析器。

语言结构折叠新增 YAML、SCSS、Less、XML、Markdown、SQL、PHP。Less/SQL 语言模块需要打包，不能用 `@codemirror/*` 通配外置；构建只外置已核对的宿主核心模块。Markdown 范围从 formatting.js 的同步导出复用现有 AST，避免分别生成两份 Markdown 解析依赖。修改后使用 `15 新增语言结构折叠.md` 验证三视图，SQL 方言过程块、PHP 外层 HTML 和 Obsidian 专属 Markdown 扩展不属于完整覆盖保证。

使用 `npm run licenses:check` 核对第三方声明；依赖变化时运行 `npm run licenses:candidate` 生成候选文本，审查后更新正式声明。除了 npm 包自身的许可证，还必须保留 Prettier 的 THIRD-PARTY-NOTICES.md 中内置依赖的完整声明。

更改前补针对性回归，修复后运行完整 check。构建成功不等于真实 UI 通过。不得因新功能重构丢失异步取消、源码范围、重复定位、输出围栏、用户设置和发布白名单的保护。

## 当前实现与收尾边界

围栏索引缓存由 formatting-entry.js 统一维护，最多两个不超过 200 万字符的精确源码快照，仅保留只读围栏记录和引用范围，不缓存完整 Markdown AST。显示定位、输入定位和格式化前后边界复核共享结果；源码变化必须重新解析，不能以行号或内容近似命中。不要再在显示层另建重复的全篇源码缓存。

Java、Python、C/C++ 已接入手动单块格式化。Java 两个 WASM 在构建时内嵌，适配器只替换资源初始化且检查唯一匹配；升级 prettier-plugin-java 时必须重新核对。Python 使用官方 CPython 3.14.10 嵌入式运行时、Black 26.10.1 及固定依赖的纯 Python wheel（仅 Windows x64）。资产在 black-runtime-assets.js 固定；clang-format WASM 23.1.1 在 managed-formatters.js 固定。版本、长度和 SHA-256 更新须重新核验来源与摘要。缓存仅位于插件 components 目录，不查找系统 PATH，不读笔记目录的格式化配置。

Black 使用隐藏的常驻 JSONL 进程，-I/-S/-B 隔离系统搜索路径与 site 配置；显式加载插件包目录，调用 format_file_contents(fast=False)。原始代码只作为 JSON 字符串传递给格式化器，不执行。分帧处理 UTF-8 与半行，核对版本和请求 id，限制响应与结果长度；20 秒超时后终止并在下次请求重启。空闲 5 分钟停止，卸载关闭输入并终止。加载图标延迟 300 毫秒，快速请求不显示。

组件下载有 90 秒超时，校验后经唯一 part 文件移入缓存，同组件并发请求合并。运行时与 wheel 解压拒绝路径穿越，展开文件在每次插件会话首次使用时逐一比对已校验的原始包，修复不完整安装。Black wheel 需要展开，不能直接 zipimport（Grammar.txt 使用文件路径读取）。下载期间卸载不提交结果，所有格式化仍走源码快照、围栏复核和编辑器事务。运行测试使用 16 多语言格式化.md。代码执行仍未实现，也不在格式化范围内。

引用和 Callout 的源码围栏可能只被宿主识别成行内代码。editorBlocks 使用已有 Markdown AST 为真实、闭合的引用围栏补充起止事件，不按文本括号或反引号计数猜测。新增回归验证源码按钮、三视图单按钮、前缀和撤销，拒绝把外层代码示例里的围栏文字当成按钮目标。

COMPONENT-NOTICES.txt 保留外部组件的 Black、CPython 和 LLVM 许可及 Java 资源适配说明，由 notices.cjs 合并进总声明并嵌入 main.js。

0.4.0 完成后本轮开发暂时结束，先在正式知识库使用，不自动扩展功能。新的明确需求再开启开发。官方市场提交暂缓，依赖下载政策与桌面版限制见 release-readiness.md，不能因本地打包成功宣布上架就绪。
