## 笔记完整性边界

换行和折叠只改变 DOM、CSS 与编辑器装饰，不写入笔记。只有手动点击格式化画刷才提交围栏正文替换；提交前核对源码、文件、视图和模式，异步期间变化或插件卸载时拒绝旧结果。围栏解析有前后校验，修改通过编辑器事务支持撤销。

最终回归覆盖 BOM、LF/CRLF、普通正文、表格、链接、行内代码、其他代码块、列表与嵌套引用。检查目标围栏之外逐字节不变、不增加零宽字符/BOM 等标记，并验证重复格式化无变化。真实 Obsidian 源码、实时预览和阅读视图中，显示开关及折叠不改变源码，格式化仅修改目标围栏，撤销恢复原文，保存后与初始文件一致。

上述是明确测试范围，不是对所有第三方插件组合的永久保证。定位不可靠时拒绝猜测；使用未覆盖的渲染插件或升级 Obsidian 后，应在副本验证再使用。

最终完整检查通过 101 项 Node 测试与 20 项基础断言；第三方许可检查通过，生产依赖审计未报告已知漏洞。实际三视图还检查了引用正文的悬停归属、折叠控件和保存后的源码一致性。

## 审查结论与修复

Codex 独立审查席位重点检查源码写入边界，没有发现可证实的外围误写或显示符号落盘问题。Antigravity 的独立静态审查核对运行源文件、构建部署及公开文档；其指出的引用正文行装饰缺失、公开说明矛盾等已修正。额外复现并修复 BOM 偏移、多行 CRLF 比较问题。全部运行文件和许可应以最终构建与测试结果为准，不以模型通过声明代替验证。

## 官方市场提交前仍需处理

当前官方可检索的[开发者政策](https://docs.obsidian.md/community-directory/developer-policies)禁止插件自行安装或更新自身及依赖。0.4.0 的 Python/C/C++ 首次使用下载并安装组件属于需要解决的上架阻断；本轮保留用于明确授权的本地试用，不能据此宣称符合官方政策。后续提交前应重新核对政策并调整依赖分发方案，不能只补 README 声明后直接提交。

[插件提交要求](https://docs.obsidian.md/community-directory/submission-requirements-for-plugins)要求使用 Node.js/Electron API 的插件限定桌面版，manifest 已设 isDesktopOnly=true。Windows x64 / Obsidian 1.15.0 是本轮完整实测环境；其他桌面系统未实测，Python 目前明确只适配 Windows x64。

[官方提交流程](https://docs.obsidian.md/Plugins/Releasing/Submit%20your%20plugin)要求公开发行仓库、与 manifest 版本完全匹配的 GitHub Release，以及 main.js、manifest.json、styles.css 附件。源码可以在同一公开仓库维护，也可以放在单独的私有仓库，并授权官方 GitHub App 读取和核对构建，见[私有源码仓库接入说明](https://docs.obsidian.md/community-directory/manage-entry)。本项目按公开源码仓库方案准备；准备流程不等于已经发布，实际仓库可见性、远端地址和最终提交仍需按用户决定执行。
