# 设计决策

本文保存已经确认的需求、取舍和维护边界，不是下一阶段的自动开发计划。功能与默认值以 README、源码和实测状态为准。

## 产品与职责

插件显示名、ID 和源码仓库名统一为 Code Block Enhancements / code-block-enhancements，作者为 ZhangWuwei。它是代码块功能增强，不是主题，也不是完整 IDE 或笔记执行环境。

| 层级 | 负责 | 不负责 |
| --- | --- | --- |
| Obsidian 与主题 | 基础编辑/阅读、字体配置、原生高亮与主题外观 | 不能假定两个视图的语法分类完全相同 |
| 用户 CSS 片段 | 明暗颜色、排版、表格、行内代码、Callout、树状数字、基础软换行 | 不修改 Markdown，不承担逐行解析或代码运行 |
| 本插件 | 续行缩进、代码内部结构折叠、显式按钮格式化 | 不接管高亮器、不强制配色或字体、不改笔记外围正文 |

插件不依赖某一份个人 CSS 才能提供核心功能；CSS 不进入插件发行包。现有 qn-* 类名是内部命名空间，不是用户可见插件名，不为改名而扩大重构。

## 源码保护与撤回的方案

显示功能不修改源码是硬约束。曾采用在围栏中写入文件名、ln/start 等显示参数的方案，用户不接受这种写法并要求移除相关功能。当前不提供文件名标题、插件行号或需要编辑 Markdown 的显示参数；这不意味着所有其他插件的这些功能必然改写源码。

逐块换行、指定行高亮等只讨论过，未纳入当前功能。不要因为其他插件支持、历史对话提过，就重新加入。代码折叠指类、函数、分支、循环等内部结构折叠，不是只将整个围栏缩成标题条。

代码格式化是唯一允许写入源码的功能，必须由当前代码块按钮显式触发。不能自动格式化、按光标移动触发、整篇重排或回退为猜测目标。

## 换行与结构折叠

软换行、前导缩进对齐与源码中的真实换行是不同概念。显示层允许长行折行；保留缩进开关只控制续行对齐，关闭不代表恢复横向滚动。

阅读视图在保留高亮的前提下逐源代码行包装；编辑器通过 CodeMirror 装饰处理。Tab 按显示宽度计算，跨行注释、嵌套 span、空行和复制文本都不能因拆行损坏。只缩小字体不能解决续行贴左，固定的全块 text-indent 也不能冒充逐行缩进。

结构范围优先使用语言解析器，不用简单括号计数。已有解析器时，注释、字符串中的括号不能当结构边界；JSX/TSX 元素也需要范围。没有对应解析器时采用通用缩进后备，忽略空行，按显示 Tab 列宽计算层级，保留同级或更浅的后续行。后备不理解语法，可能折叠字符串或注释中的缩进文本；无缩进层级的代码不生成后备范围。已有解析器即使返回空范围也不混入后备，避免覆盖语法判断。策略参考 [VS Code Folding](https://code.visualstudio.com/api/language-extensions/language-configuration-guide#folding)，不是复制其完整实现。

折叠箭头靠近代码但须留出间距，沿用宿主三角样式，仅悬停或聚焦相关行时显示。展开省略号须与代码基线协调，不能用明显悬浮的装饰按钮。提示使用“单击以折叠范围”“单击以展开范围”。

箭头放在代码已有的左侧留白内，不额外增加固定字符宽的通道，不因启用折叠推移代码起始位置；编辑器沿用宿主的基础代码行留白。

实时预览的 Callout 可能是渲染组件而非普通编辑器行。控件手势必须阻止冒泡/选择，不能因为点折叠就进入整块源码。离屏但仍保留在原生虚拟区段缓存中的块，不能误判为销毁而丢失折叠状态。

## 格式化边界

原有语言使用锁定的 Prettier 3.7.4 npm 包及所需 standalone 解析器，随 bundle 分发，不加载用户配置脚本。Java 使用 prettier-plugin-java 2.11.0，所需两份 WASM 内嵌并首次使用时初始化。Python 使用 Black 26.10.1 与插件私有 CPython 3.14.10 嵌入式运行时（首期 Windows x64），C/C++ 使用 @wasm-fmt/clang-format 23.1.1 WASM；两者首次使用下载固定版本并校验长度及 SHA-256，之后读取私有缓存。Python 使用隐藏的常驻进程避免每次启动单文件 exe 的开销，保留格式化语义检查，不开启 HTTP 服务，不依赖 PyInstaller 私有机制。无需另装 Obsidian/VS Code 插件或系统 Python 环境。

格式化不等于只改空格：引号、分号、尾随逗号和换行等也可能改变。保持程序含义是目标，不是对任意输入已证明语义等价。代码示例可能不完整，失败必须保留原文。

| 保护 | 要求 |
| --- | --- |
| 支持范围 | 规范化语言别名后按白名单选择引擎；支持折叠不代表支持格式化 |
| 定位 | 结合文件、源码快照、围栏范围、当前容器/阅读区段核对，不取第一个相同文本 |
| 嵌套 | 保留列表、引用、Callout 的前缀、围栏与外部正文 |
| 提交 | 异步结果提交前重查文件、内容、视图、模式及插件卸载状态 |
| 保存与撤销 | 使用编辑器事务；不能只改隐藏阅读编辑器后误以为已经保存 |
| 取消 | 用户编辑或切换期间丢弃过期结果，不抢回用户选择的视图 |
| 大小 | 保留笔记/代码块大小限制；当前没有 Worker 或可中断超时保证 |

“深入格式化 Vue 和字符串内代码”是显式开关，新安装默认开启；运行时仅严格 true 才开启。关闭时不深入改写标签模板字符串及 Vue 内的脚本、样式、插值；开启可能改变字符串的实际内容及运行结果。不能每次启动强制重置用户已保存的选择。

分号默认开启，单引号偏好默认关闭；单引号开关关闭表示优先使用双引号，不表示保留源码中的原有引号。设置说明须明确两种状态都会在手动格式化时按偏好改写引号，以及减少转义时的例外。

发行版暴露的格式化选项默认值除参考行宽 100 外，均与 Prettier 3.7.4 一致。末尾逗号提供 none/es5/all 三选一，默认 all；箭头函数参数括号提供 always/avoid，默认 always，avoid 是移除可选括号，不是保留输入。标签每行一个属性默认关闭，关闭不禁止参考行宽触发的换行。三项均只作用于下一次手动格式化，不扩大到整篇或自动格式化。个人选择与发行默认值分开：本机测试库保留末尾逗号 none、标签结束尖括号跟随最后一个属性、深入格式化内嵌代码关闭，不在升级时覆盖。

字符串引号偏好以双引号/单引号下拉框呈现，继续保存原有 formatSingleQuote 布尔值，兼容已有设置。页面将共用触发条件集中放在格式化分组，避免每项重复默认值与点击操作。

增加八项稳定原生选项：useTabs=false、bracketSpacing=true、quoteProps=as-needed、jsxSingleQuote=false、objectWrap=preserve、bracketSameLine=false、vueIndentScriptAndStyle=false、htmlWhitespaceSensitivity=css。均沿用 Prettier 3.7.4 默认值；实验性选项不在本次范围。HTML 空白与模板字符串相关设置保留实际文本/显示行为变化的边界说明。

## 按钮与设置交互

- 格式化使用画刷，和原生复制按钮并列；编辑器中固定在代码块开头右侧，不随光标上下移动。
- 三种视图统一为阅读复制按钮的固定尺寸 32×28px，不跟随编辑器语言标签长度变宽。
- 默认提示“格式化此代码块”；悬停变化只作用当前按钮，不因整个代码块悬停就误高亮。
- 成功对号约保留 1 秒，移出不立刻恢复；文字可隐藏。再次点击无变化时显示“已格式化”。
- 失败显示叉及容易理解的原因，不弹全局 Notice；错误位置只属于所点按钮，不能串到重复块或长期覆盖正文。
- 未支持语言默认淡色画刷，悬停/聚焦按钮才显示禁止符号和说明，点击不进入格式化。
- 设置按显示功能、代码块格式化及当前工具子组组织；不预留没有功能的空白占位。行宽是排版参考，不是强制截断；非法输入不保存。
- 分组无障碍名称用 role/aria-labelledby，不用整组 aria-label 制造多余气泡。宿主事件及延迟应核对当前版本，脚本事件测试与物理鼠标测试分别记录。

## 主题集成的长期取舍

用户以浅色笔记阅读为主，偏好自然、克制、能区分语义的代码颜色；深色编程习惯不意味着笔记必须使用黑色代码块。字体、比例和颜色属于外观层，不能为了修折行擅自切换高亮器或更换用户字体。

Prism 与 CodeMirror 识别类别和颜色变量映射不同，同一调色板不保证两个视图逐 token 一致；CSS 无法给不存在的语法 token 补识别。属性、数值、标点、运算符应分别保留颜色角色，不能为“低干扰”把语义层次全部合并。

个人表格/字体问题的具体历史写在外部片段注释与本机交接记录，不写进插件运行样式。主题更新后的覆盖关系需要重新核对，不能仅凭主题名宣称适配。

## 生命周期、审查与发布

插件不能在初始化或设置保存时主动清空全部阅读页，只增强已挂载 DOM，局部测量折叠高度并合并更新。后台节流与宿主热重载可能导致阅读调度暂停；不能以永久关闭节流、轮询私有队列或强制全局重绘掩盖问题。保留故障证据，明确已复现路径与未还原的历史事件。

开发默认在独立测试 Vault；正式 Vault 只安装发行文件，不直接编辑。先修改、测试开发版，再经授权发布；不能因为改动很小跳过测试版。机器特定测试与独立模型报告不是通用兼容保证，主代理仍负责实际核验。

独立模型审查先提供必要规则和 Skill、明确只读范围。过去 Opus/Gemini 报告既有可采纳发现，也有被实验否定的判断；不得把一致意见或 SUCCESS 当实测。必要时用最小新证据复核，不重复全量审查。

源码仓库采用 MIT，保留 LICENSE 与完整第三方声明；构建将两份声明全文嵌入 main.js 注释。发行运行白名单仅 main.js、manifest.json、styles.css，另附校验表；不得再另附独立声明文件，不覆盖用户 data.json。

依赖升级、运行逻辑变更、公开文件范围变化应做对应验证。Git 提交、添加远端、推送、正式部署分别遵守用户授权；测试通过不等于自动获准执行它们。

## 后续开发的停靠点

Java、Python、C/C++ 格式化现已实现；Black 使用原生默认值，clang-format 使用 LLVM 默认值并关闭 include 重排，不将 Prettier 偏好默默映射到不同工具。先交付固定风格与可靠失败反馈，额外设置后续按实际使用讨论。代码执行没有实现，不能把格式化的安全假设直接用于运行任意代码。
