# 变更记录

## 0.4.3 (2026-11-06，本地试用)

- 格式化按钮复用原生复制按钮及编辑器语言标记的主题样式入口，不再单独覆盖悬停背景和图标颜色；保留独立点击处理、尺寸、定位和键盘可达性，定位时排除自身。
- 修复 0.4.2 卸载清理仍引用已移除缓存名导致的热重载中断；改为清理共享围栏缓存，并补充卸载及按钮操作回归。

## 0.4.2 (2026-11-06，本地试用)

- 将显示定位与格式化的围栏解析缓存合并，复用两个精确源码快照，避免长笔记重复执行整篇 Markdown 解析；不保留完整 AST。
- 缓存结果及嵌套范围只读，内容变化后重新解析；保留输出围栏复核、源码快照和过期结果检查。新增缓存不可变、失效与容量回归。

## 0.4.1 (2026-11-06，本地试用)

- Prettier 从 3.6.2 升至 3.7.4，提供 Java 扩展所需的注释祖先节点接口，修复带注释的条件语句格式化失败。保留全部用户设置；升级不自动格式化笔记。
- 无可识别语法诊断的格式化器异常改为内部错误提示，不再一律归咎于代码语法。失败仍不写回源码。
- 补充注释保留及重复格式化稳定性的回归测试；其他语言排版可能随上游修复微调。

## 0.4.0 (2026-11-05，本地试用)

- 新增 Java（Prettier Java）、Python（私有 CPython + Black）、C/C++（clang-format WASM）格式化；组件固定版本、长度与 SHA-256，失败不写回源码。Python 当前仅支持 Windows x64。
- Python 改为隐藏常驻进程，空闲 5 分钟释放；短代码重复格式化不再每次启动单文件程序。加载图标延迟 300 毫秒显示。
- 新增 YAML、SCSS、Less、XML、Markdown、SQL、PHP 结构折叠及 yml/md/mjs/cjs 别名。没有结构解析器的语言按缩进兜底；SQL 主要识别语句和括号组。
- 补齐源码视图引用围栏的按钮、正文行悬停与折叠定位；箭头使用既有留白，不额外推移代码。
- 修复带 BOM 的笔记围栏偏移；多行 CRLF 代码统一逻辑比较并保留输出行结束符，避免错误地拒绝格式化。
- 保留 18 个设置，统一工具概览、分组、可展开说明与示例；Java 并入 Prettier 并明确扩展归属。
- Prettier 偏好除参考行宽 100 外与 3.6.2 默认一致：末尾逗号 all、箭头参数括号 always、标签每行一个属性关闭；升级保留已保存选择。
- 发行元数据限定桌面版。打包拒绝用不同内容覆盖同一版本，运行安装仍只有三个文件，不覆盖用户设置。
- 完成独立静态审查及笔记边界回归；当前依赖自动下载方式不作为官方市场就绪方案，后续须解决政策限制。

以下 0.3.x 为历史本地版本记录，不表示已经公开发布。

## 0.3.4

- 初始化不再主动清空所有阅读页，改为幂等增强已挂载代码块，减少后台重绘引发空白的机会。
- 扫描时保留仍在原生虚拟区段缓存中的离屏代码块，避免丢失折叠状态；卸载时清理扫描创建的组件。
- 删除设置分组的多余悬停提示，保留无障碍名称；明确单引号及 Vue/字符串内代码格式化的含义与风险，默认关闭后者。
- 将完整自有与第三方许可声明嵌入主 bundle，兼容社区安装器只下载三个运行文件的分发方式。
- 增加不清空原生区段、离屏缓存保留及嵌入许可完整性回归测试。
- 通过 Windows / Obsidian 1.15.0 实机验收，保留最低版本 1.14.5；Mermaid 新渲染结果不由本插件接管。

## 0.3.3

- 改善 JSX/TSX 结构折叠，消除插件与原生箭头重复，保留不支持行的原生回退。
- 统一不同语言代码块的留白与格式化按钮尺寸。
- 修复实时预览 Callout 折叠手势误进入源码的问题。
- 通过源码容器／当前阅读区段定位重复代码，格式化前核对完整范围。
- 修复默认折叠 Callout 的反馈定位；成功对号移出后仍短暂保留。
- 不支持语言采用白名单拦截，悬停按钮时显示禁止符号。
- 折叠后局部更新高度缓存，设置切换不再强制整篇重渲染。
- 设置页面按显示与格式化工具分组，补充输入校验和语法选项说明。
- 整理公开源码范围、MIT 许可及发行文件清单，保留第三方声明。
- 补全 Prettier 内置解析器的第三方声明，并校验许可文件与锁定依赖一致。
- 增加默认关闭的“格式化嵌入语言”开关，默认保留标签模板字符串内部文本。
- 修复阅读模式切换期间用户编辑导致取消后仍被抢回阅读视图的问题。
- 最低声明版本收敛为本轮实际验收的 Obsidian 1.14.5，不再暗示已验证旧版内部接口。

- 增加 Callout 定位、反馈隔离、保存和滚动恢复等保护。
